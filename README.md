# 轻录

Mac 本地录音与回放（v0.3）：可选仅系统声音、仅麦克风、两者都录，可在录制中切换来源和麦克风，支持暂停/继续/结束保存。窗口内提供录音列表、可恢复删除和播放器，无账号、网络上传、驱动安装或额外音频软件依赖。

## 使用

1. 打开 `~/Applications/轻录.app`。若从压缩包安装，将 `dist/轻录-mac.zip` 解压到用户的“应用程序”文件夹后打开。建议保持安装位置，避免反复要求确认录音权限。
2. 在“录音来源”选择仅系统声音、仅麦克风或两者都录；选择会自动记住。录制过程中也可切换，正在处理切换或重连时会暂时锁定控件。
3. 需要麦克风时，默认“自动（优先内置麦克风）”，也可手动选择耳机或外接麦克风。仅系统声音不要求麦克风权限；仅麦克风不初始化屏幕采集或要求屏幕权限。双路模式需要两种权限。
4. 点击“开始录音”，按 macOS 提示授权。系统声采集不保存屏幕画面。如系统要求重启应用，退出后重新打开。关闭窗口后应用留在菜单栏，仍可停止和保存。
5. 录制时可点“暂停录音”，再点“继续录音”接着录；暂停时长不加入成品。点击“结束并保存”结束本次录音，文件自动进入右侧“我的录音”。

默认目录：`~/Music/轻录`，可以通过“更改…”选择其他文件夹。格式：48 kHz、双声道、AAC 192 kbps、`.m4a`。静音时段同样计入录音时间，文件不会自动跳过静音。

## 录音列表与播放

- 自动读取当前保存目录及本应用已完成会话中记录的历史目录，兼容已有M4A。也可显示这些目录中的WAV、CAF、MP3、AIFF；不递归扫描整台电脑。
- 列表展示名称、日期、时长及来源（旧版没有来源元数据时不推断）；设备切换提示可在选中文件后查看。
- 点击文件可选中；播放按钮在应用内播放。支持暂停/继续、停止归零、拖动进度、前后10秒和音量控制。Finder按钮定位原文件。
- 录音开始会暂停回放；录制和保存期间禁用播放器，避免外放再次进入麦克风。
- 新增或移动文件后点击列表刷新；应用重新激活和保存完成也会刷新。
- 每条录音右侧有删除按钮，确认后移到废纸篓，可在 Finder 中恢复；不会永久删除。若该文件正在播放，先停止并释放播放器再移入废纸篓。移动失败时显示错误，不以永久删除作为替代。录音或保存期间暂不删除历史文件。

## 暂停、结束与录制中切换

- 暂停会停止系统声和麦克风采集，计时冻结；继续后接在同一个M4A里，不插入暂停期间的静音。暂停前已录内容会同步到缓存，暂停状态异常退出仍可恢复。
- “结束并保存”可以在录音或暂停状态点击，不会丢弃本次内容。应用正常退出时也会先保存暂停中的录音。
- 暂停期间可以调整来源和麦克风；继续时按新设置启动。暂停期间不持有防闲置睡眠断言。
- 正在录音时可直接切换三种来源和麦克风，计时和文件保持连续；切换处可能短暂静音。保留的声源继续，关闭的声源在边界后不再写入；切换输入时不重放旧设备的缓冲。
- 新启用的来源需要相应权限。权限核验前保留原来源录制，未获权限则保持原设置并提示。切换和自动重连串行处理，避免操作互相覆盖。
- 录音列表会标记“来源已切换”，选中后可查看暂停、继续和切换记录。这些是操作记录，不代表每段声音都已实测完整。

## 耳机插拔和声源重连

- 插拔耳机、输出设备变化或麦克风暂时没有数据，不会主动结束整段录音；时间继续累计，最后仍是同一个M4A。
- 自动选择优先保持内置麦克风，插入耳机不会强行改用耳机麦克风。手动所选麦克风仍可用时保持选择；掉线后依次回退内置麦克风、系统默认输入或其他可用输入，所选设备返回时会尝试恢复。
- 没有可用麦克风时显示等待连接，其余已启用声源继续录制；仅麦克风模式会保留相应静音时段。连接恢复后自动继续，不裁剪时间。
- 系统声采集失败会重连；重试采用1、2、4、8秒间隔，避免反复立即重启。界面显示正在重连或已恢复，并把提示写入会话记录。
- 设备切换可能短暂静音，不保证硬件切换期间没有丢失声音；录音记录会保留提示，不将这类片段描述为无缝。

## 连续录制与恢复

- 目标使用场景为连续1—4小时。没有人为时长上限，实际可录时长取决于磁盘和设备状态。
- 声音持续写入10秒PCM缓存片段；4小时缓存约2.76GB，按标称码率估算M4A约346MB（实际随内容变化）。停止后完成导出校验才删除缓存。录制前请预留至少4GB可用空间，以覆盖4小时场景。
- 缓存目录：`~/Library/Application Support/LightRecorder/Sessions`。不要在录制或保存过程中清理此目录。
- 强制退出后重新打开应用，可在“等待保存”列表恢复。已完成同步写入的片段可恢复，最后一个正在写入的片段尽量恢复完整采样帧；无法保证断电前最后一瞬间的数据。
- 导出失败不会删除缓存。可先“更改…”保存位置，再点击“恢复保存”。正常录完但导出失败的文件仍按正常录音保存；意外退出或睡眠中断的录音标记“中断录音”。设备切换本身不结束录音，只记录提示。
- 录制时防止闲置自动睡眠，锁屏不主动停止。请勿主动睡眠或合盖：系统停止执行期间无法采集，应用将尽力保存此前内容，不会把缺失期间标为完整录音。
- 外放可能被麦克风再次收录，双路录音建议戴耳机，无回声消除。

## 构建与检查

当前交付针对 Apple Silicon Mac，本机已安装的 CommandLineTools 即可构建，无需完整 Xcode。使用 macOS 15及以上的系统API；旧版系统及其他机型尚未实测。

从源码开始：

```sh
git clone https://github.com/Sinclair2003/light-recorder.git
cd light-recorder
```

```sh
./scripts/build.sh
./scripts/install.sh
./scripts/test.sh
```

`build.sh` 编译 release 可执行文件，使用项目内图标打包并本地签名 `.build/packaged/轻录.app`，输出 `dist/轻录-mac.zip`。文稿目录的文件提供程序可能随后给其中的 `.app` 附加 Finder 元数据并影响签名，因此构建后立即将规范文件内容打包，实际使用安装后的版本。`install.sh` 安装到 `~/Applications/轻录.app`；更新已有本应用前会保留一个隐藏备份，不覆盖其他同名应用。这是本机自用版本，没有用于跨机器分发的 Developer ID 签名与公证。

`test.sh` 运行自带检查程序，不依赖 XCTest。v0.3共32项检查，包含暂停时间排除/继续拼接/暂停中结束与恢复、热切换声源过滤与增益、麦克风旧代次过滤、权限增量策略、废纸篓移入和恢复，以及前版混音/播放/缓存/长文件回归。废纸篓检查只使用自建UUID临时文件并恢复，不动用户录音。生成 `artifacts/self-test-report.json`；未开启长测试时跳过2项4小时检查。

长时间离线验证：

```sh
RECORDER_LONG_TEST=1 RECORDER_LONG_EXPORT=1 ./scripts/test.sh
```

该命令使用合成音频，验证4小时时间线、1440个缓存片段及单个4小时M4A的长度与代表性位置解码，临时音频测试结束后清理。它不录制麦克风或系统声音。

如果在受限开发沙箱中出现 CoreAudio `fmt?` / `1718449215`，需要在正常的本机终端运行检查；已用独立合成声音探针确认，沙箱会限制系统压缩音频编码服务。不要因此关闭系统隐私保护。

## 真实录音验收

自动检查和打开窗口不等于实录验收。需用户主动开始：

1. 分别用三种模式录制30—60秒：系统声模式确认没有麦克风，麦克风模式确认没有系统声，双路模式确认两路都有。在内置播放器回放并检查进度、暂停和拖动。
2. 录制时关闭窗口，从菜单栏恢复，再停止。核对文件连续。
3. 连续录制4小时，在开始和结束时用可对照信号检查两路同步，核对时长、末尾播放、锁屏期间连续性及内存变化。
4. 录制过程中插拔耳机，确认计时不停止、麦克风回退/恢复提示出现，停止后只有同一个完整时间长度的文件；检查切换处是否有短暂静音。系统声模式也验证输出切换。导出失败后确认可更换目录重试。
5. 录一段声音，暂停几秒再继续；结束后核对音频没有暂停时段、仍是同一个文件。暂停后直接结束也应正确保存。
6. 正在录制时依次切换来源和可用麦克风，检查选择即时生效、停用声音不再混入，拒绝新权限时保留原模式。用不需要保留的文件验证删除和从废纸篓恢复。

当前验证范围和复现方法见 [测试说明](docs/TESTING.md)。离线检查不能替代真实设备验收。

## 项目结构

- `Sources/RecorderCore`：PCM格式解码、时间线混音、缓存与导出。
- `Sources/RecorderApp`：权限、采集、设备与睡眠处理、中文窗口和菜单栏。
- `Tests/RecorderCoreTests`：无需XCTest的离线功能检查。
- `docs/TESTING.md`：离线检查的覆盖范围与真实设备验收步骤。

录音、构建缓存、安装包和本机内部记录不随源码提交。运行时生成的音频仍保存在用户选择的文件夹中。

应用自身没有网络调用；没有实现云端转写或自动启动录音。
